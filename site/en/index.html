QUICK ANSWERS

Everything in 30 seconds

Is TypeZero really free forever? What do API calls cost?
Yes—MIT open-source with zero subscription fees or paywalls. Run 100% free offline with the embedded 886MB SenseVoice FP32 + local Ollama, or plug in your own OpenAI / Groq / DeepSeek / Gemini API key at raw provider rates (typically a few cents per day for thousands of words).
Can I start with just an OpenAI API key?
Absolutely. v0.4.5 ships with native OpenAI (gpt-4o-mini-transcribe) and Groq (whisper-large-v3-turbo) speech cards. Enter your OpenAI key once and TypeZero automatically reuses it for both voice transcription and LLM formatting.
Do my transcripts or API keys ever touch a developer server?
Never. There is no TypeZero backend relay, no user account, and zero telemetry. API keys are encrypted in macOS Keychain, requests go directly to your chosen provider, and the full codebase is open for audit.
Which Macs are supported? Will Gatekeeper block it?
Supports Apple Silicon (M1 / M2 / M3 / M4) running macOS 14 Sonoma or later. Every DMG release is signed with Apple Developer ID and Apple notarized & stapled—drag into Applications and launch with zero warnings.
