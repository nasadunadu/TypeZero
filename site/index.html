🙋 常见问题

关于安装、免费政策与桌面搭子的常见解答

TypeZero 真的是永久免费的吗？赠送的 1 个月云端额度到期后怎么用？
软件本体基于 MIT 协议开源，永久免除任何月费或年费。新用户注册即免费获赠 1 个月云端畅用额度（300 分钟语音识别 + 1,500 次智能润色）。到期后，你可以直接切换软件内置的本机离线模型永久 ¥0 使用，也可以参考 2 分钟 API 开通教程 绑定自己的豆包、DeepSeek 或 OpenAI 接口按官方底价直连使用。
完全不懂技术配置的新手，下载安装后能直接使用吗？
可以直接使用。macOS 安装包已通过 Apple Developer ID 签名与官方公证，零安全拦截弹窗；拖入应用程序启动并完成麦克风与辅助功能授权后，登录账号即可在任意输入框按快捷键说话出字。
桌面上的小黑猫会遮挡日常办公点击吗？键盘闪光和打字声能否关闭？
不会干扰办公。你可以在主面板「🐱 桌面搭子」中开启鼠标点击穿透，也可以自由拖拽位置与缩放尺寸。针对极简办公需求，键盘呼吸跑马灯、按键柔光、浮动键帽气泡、机械轴打字声以及换猫吵架配音均设有独立开关，随时可一键关闭。
如何在客户端里触发「双猫顶额头吵架换班」动画？
打开 TypeZero 主窗口左侧栏的「🐱 桌面搭子」页面，在「品种与换班」中选择另一只猫咪（例如从小黑猫切换为挖煤暹罗猫或橘白黄粽子），桌面工位即会完整播放新猫走入、炸毛顶额头对峙交接动画。
支持在哪些软件里语音输入？
支持系统全局所有可输入文本的光标位置——无论是微信、飞书、钉钉、Slack、浏览器网页编辑器、Notion、飞书文档、Word、备忘录还是各类代码与 AI 对话窗口，按住快捷键说话松手即可直出。
我的语音内容和个人词库隐私安全吗？
非常安全。云端引擎采用加密流式传输，识别返回后当场销毁音频片段，服务端不留存录音或文本；个人专属词库、历史记录与 API 密钥（加密存于系统 Keychain）均 100% 保存在你的本地电脑中。
