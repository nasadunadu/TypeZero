30 秒了解全部细节

永久免费开源，那 API 花费高吗？
软件本体 MIT 永久免费，零订阅费。你可以用本机 886MB SenseVoice FP32 完全免费离线跑；自配 DeepSeek / OpenAI / Groq / 豆包官方 API，每天口述几千字通常仅需几分钱。
只有 OpenAI API Key 能不能直接开用？
可以。v0.4.5 内置 OpenAI（gpt-4o-mini-transcribe）与 Groq（whisper-large-v3-turbo）云端语音卡片，填一次 OpenAI Key 自动双端复用，零额外注册门槛。
我的聊天记录和密钥真的 100% 留在本机吗？
100%。无开发者中转服务器、无账号体系、无埋点统计。API Key 加密存放在 macOS Keychain，所有代码全量开源可审计。
支持哪些系统？macOS 和 Windows 首次打开会被拦截吗？
macOS 支持 Apple Silicon（M1–M4）与 macOS 14+，安装包已通过 Apple Developer ID 签名与云端公证装订，拖入 Applications 零弹窗。Windows 支持 Windows 10/11 (x64)，采用 Rust + Win32 + Tauri v2 原生构建，用户态一键安装免管理员权限；因开源版本暂未采购商业代码签名，首次运行若弹出 Windows SmartScreen 蓝色提示，点「更多信息 → 仍要运行」即可。
