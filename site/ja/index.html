音声入力と同時に音楽・動画の再生音を自動ミュートし、録音終了と同時に元の音量へ戻します。

QUICK ANSWERS

30秒でわかる詳細 FAQ

本当に永久無料ですか？API のコストは高くなりませんか？
はい。MIT オープンソースでアプリ課金は一切ありません。内蔵の 886MB SenseVoice FP32 とローカル Ollama を使えば完全無料・オフラインで動作します。OpenAI / Groq / DeepSeek / Gemini 等の公式 API を使う場合も、1日数千文字の入力で数円〜十数円程度です。
OpenAI の API キーしか持っていませんが、すぐ使えますか？
もちろんです。v0.4.5 から OpenAI（gpt-4o-mini-transcribe）と Groq（whisper-large-v3-turbo）にネイティブ対応。OpenAI キーを一度入力するだけで音声認識と AI 整形の両方で自動共有されます。
入力内容や API キーが開発者のサーバーに送られることは？
100% ありません。中継サーバー・アカウント登録・行動トラッキングは一切ゼロです。API キーは macOS キーチェーンに暗号化保存され、すべてのソースコードが GitHub で公開されています。
対応 Mac は？起動時にセキュリティ警告は出ませんか？
Apple Silicon（M1 / M2 / M3 / M4）および macOS 14 Sonoma 以降に対応しています。公式 DMG は Apple Developer ID 署名と Apple 公証（Notarized & Stapled）済みのため、Applications にドラッグするだけで警告なく起動できます。
