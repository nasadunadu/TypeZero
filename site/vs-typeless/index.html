哪类用户最适合从 Typeless 切到 TypeZero？

1. 高频中文 + 英文术语混说的开发者与产品经理

日常在 Cursor、Claude Code、飞书、Notion 里写 Prompt、写评审或发消息，需要同时识别英文技术缩写（SEO / API / Swift / Supabase）与中文长句，TypeZero 的个人词库自学习与中英混排优化显著优于纯海外产品。

2. 拒绝订阅税、手头已有 API Key 的效率党

如果你本来就有 DeepSeek、豆包、OpenAI、Gemini 或 Groq 的 Key，把 Key 填进 TypeZero（仅存在本机 macOS Keychain），就能以不到订阅价 1/20 的成本获得同级别甚至更快的体验。

3. 对代码/会议隐私敏感、需要高铁飞机断网可用

TypeZero 经过 Apple Developer ID 公证且 MIT 开源，无任何第三方中转服务器；开启本地 SenseVoice FP32 后，哪怕完全断网依然保持高准确率输入。

4. 什么时候仍建议选 Typeless？

如果你完全不想申请任何 API Key、只说纯英文、且不介意每月支付 $10–$15 订阅费图个开箱即用，Typeless 依然是成熟选择；除此之外，TypeZero 在速度、中文、成本与隐私上全面领先。

常见问题（FAQ）

TypeZero 能完全替代 Typeless 的去口水话和自动排版吗？

可以。TypeZero 内置完整的五维语义整理：自动去掉「嗯、啊、那个」等口水词、识别句中反悔自我纠正、自动转为有序/无序列表、长独白分段以及中英文盘古空格，并专门防呆处理了飞书/Notion/Cursor 的 Markdown 自动列表重复。

自配 API（BYOK）配置复杂吗？每月要花多少钱？

首次打开自带 3 步引导向导，粘贴 Key 勾选卡片即生效（若填 OpenAI Key 可同时驱动语音识别与排版）。按日均输入 3000 字算，用豆包或 DeepSeek 每月 API 账单通常不到 ¥3；纯本地 SenseVoice 模式为 0 元。

支持哪些 Mac 机型？需要关闭系统安全保护吗？

支持 macOS 14.0+ 的 Apple Silicon（M1 / M2 / M3 / M4 系列）Mac。安装包已通过 Apple Developer ID 正式签名与公证，无需任何绕过 Gatekeeper 的命令行操作，拖进「应用程序」即可运行。
