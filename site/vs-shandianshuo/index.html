如何选择：闪电说 vs TypeZero？

选 TypeZero 的理由

你在意代码开源与隐私安全（日常处理公司代码、保密文档、会议纪要，不想录音经过第三方闭源中转）、想自由使用自己手头的 DeepSeek / 豆包 / OpenAI / 本地 Ollama 模型、且希望零会员费长期稳定使用。

选闪电说的理由

你完全不想接触 API Key 配置、不在意闭源与账号登录、需要 Windows/移动端多端同步生态，那么商业化封装的闪电说上手成本更低。

常见问题（FAQ）

从闪电说迁移到 TypeZero，快捷键习惯能无缝保留吗？

可以。无论你习惯按住右 Option、Fn、右 Command 还是自定义组合键，TypeZero 都能在引导向导中一键设置，并且自带 140ms 防误触机制，打字按 ⌘+C 或 ⇧+A 绝不误触发。

不想花钱买 API，纯离线能用吗？

可以。TypeZero 内置完整的 C++ sherpa-onnx 886MB SenseVoice FP32 离线语音模型，不填任何云端 Key 也能 0 元离线识别中文、英文、粤语、日韩语；如果本机跑了 Ollama 或 LM Studio，连语义排版也能 100% 离线免费完成。

在飞书、Cursor、Notion 里用会有奇怪的排版 Bug 吗？

不会。TypeZero 专门针对国内高频编辑器做了工程适配：自动加中英文盘古空格、自动识别 1. 2. 3. 列表并防止飞书/Notion/Cursor 自动补全导致的 2. 2. 序号重复，且上屏后自动恢复你原本的剪贴板内容。
