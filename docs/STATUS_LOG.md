# TypeZero 工程现状与架构演进日志 (v0.4.2 开源发布基线)

## 一、 当前产品与系统状态总览

**TypeZero** 是一款基于纯原生 Swift + C++ 构建的 macOS 极低延迟 AI 语音输入与结构化排版应用，核心体验对标 **Typeless**、**Wispr Flow** 与 **豆包输入法**，主打 **「火山豆包流式大模型 2.0 (`Seed-ASR`) 声学双擎 + 本机 886MB 满血 FP32 离线热备 + 云端亚秒级 SSE 结构化整理 + 模糊声韵专属词库」**。

| 核心模块 | 当前生产配置与实现状态 | 实测性能 / 质量基线 |
| :--- | :--- | :--- |
| **声学听写双擎底座 (ASR)** | **主力**：火山豆包流式语音大模型 2.0 (`Seed-ASR` / `volc.seedasr.sauc.duration`，TLS 会话预热 + `60ms` 极速抢首帧 + 屏幕/剪贴板/上文动态优选 Top 65 热词）；**离线满血热备**：内嵌 C++ `sherpa-onnx` + 本机 `886MB SenseVoice FP32` 无损模型 | 真声实测收尾定稿仅 **`121ms`**，专有名词声学一次命中；飞机无网或弱网断连时 **`0` 丢字自动无缝接管**回本机 FP32 |
| **原生前端流式打字机** | 独立 `.userInteractive` 实时线程 + **iPhone 高刷级单字弹出 (`11ms–18ms`, 首字 `0ms` 瞬发)** + 云端直通零扣字 + **说话中途 `<=6` 字局部回退自纠错** | 彻底拆除旧离线防抖减速锁，还原豆包手机端颗颗瞬跳与边说边改错手感 |

## 二、 第一阶段已攻克的核心工程难关记录

1. **修饰键污染合成输入隔离**：采用 `.privateState` 事件源并强制清零 `CGEventFlags(rawValue: 0)`，同时为所有自发合成事件打上专属硬件签名 `0x545A_5359`（`"TZSY"`），彻底解决物理按住/点按 `Fn` 时污染退格键或误判组合键导致第二次按键停止失灵的问题。
2. **Tap-to-Toggle 快门级启停状态机**：首次点按松开即免提连续口述，录音中再次按下触发键在 **按下沿 (`0ms`)** 即刻快门刹停，`Esc` 一键取消并自动回撤当次草稿。
3. **Electron / Chromium 跨进程输入兼容**：绕过 Chromium 对 `AXSelectedText` 假返回 `.success` 的陷阱，采用零修饰符 Unicode `CGEvent` 流式注入 + `Shift+Return` 安全框内软换行 + 剪贴板快照无损回滚兜底。
4. **Markdown 智能编辑器双倍列表序号抑制**：针对 Antigravity / Notion / 飞书等编辑器在列表行按 `Shift+Return` 自动补全 `2. ` / `3. ` 的行为，实现流式行首探测跳过与终态真实 DOM 值对账去重，消除 `2. 2. ` 重复字符。
5. **隐藏思维链延迟排雷**：查明 `deepseek-flash` 默认开启 `effort: high` 思维链（空耗 `~1000ms`），显式注入 `"thinking": {"type": "disabled"}` 并将动态变量后移至 `user` 消息以 100% 命中静态 `system` KV Cache，首包延迟提速 **5.3 倍**。
6. **25dB 耳语自动增益 (Whisper Boost AGC)**：内置软拐点自动增益放大（最高 `7.5x` 线性增益配 `tanh` 软限幅防爆音），支持深夜或办公室极低音量气声口述。
7. **失焦安全救生舱 (Safety Vault)**：当光标未聚焦在任何可编辑输入框时，自动将整理结果存入系统剪贴板并保留最近 5 条菜单栏一键回放记录，永不丢稿。

## 三、 代码质量与健壮性基线

- **编译器严格检查**：Swift 6 工具链 Release 构建 **0 Errors, 0 Warnings**。
- **零强制解包与崩溃防御**：全库清除所有 `as!`、`try!` 与 `.first!` 强制解包；所有跨进程 `AXUIElement` / `AXValue` 指针均通过 `CFGetTypeID` 严格验型并设置 `35ms` IPC 超时上限；`CSherpaOnnx` C 桥接层具备完整空指针与 OOM 回收保护。
- **会话重入互斥保护**：`AppState` 内置 `isSessionActive` 与 `isFinalizingSession` 双状态锁，杜绝快速连按快捷键引发的并发交叉注入。
- **内置回归测试套件**：通过 `./scripts/run-tests.sh`（或 `TypeZero --self-test`）在纯 CommandLineTools 环境下 50ms 内执行 **34 项核心确定性断言**（覆盖模糊声韵骨架、词条改名合并去重、双倍列表头折叠、盘古间距与 ITN、钥匙串槽位隔离、多相抗混叠 `48kHz -> 16kHz` 重采样、本机 `886MB FP32` 满血底座探测、多段落改字自学习词边界对齐、选中语音纠偏入库、动态语境热词注入、胶囊微符计数模式、`<=28` 字干净短句直通判定、左右修饰键硬件隔离、自定义组合键格式化与多服务商模型状态隔离），当前通过率 **34 / 34 (100%)**。
